# 💰 清爽记账 (My Ledger) - 本地私密极速记账应用

> **完全免费、终身无会员收费、零广告、数据 100% 存储在你的本地设备。**

---

## 🌟 核心功能亮点

1. **记一笔 & 极速计算键盘**：
   - 支持「支出 / 收入 / 转账」三种类型切换。
   - 内置单手快捷数字计算键盘（支持快速加减算账）。
   - 内置 20+ 精美分类图标（餐饮、交通、购物、娱乐、工资、奖金等），支持快速选择与备注。

2. **多账户与资金资产管理**：
   - 微信零钱、支付宝、银行储蓄卡、信用卡（负债）、现金等账户。
   - 实时计算「净资产 = 总资产 - 总负债」，账户间支持快速互转与还款。

3. **智能统计与可视化图表**：
   - 月度收支趋势分析、日均支出统计、最大单笔支出标记。
   - 分类占比环形饼图与支出榜单排名。
   - 每日开销走势柱状图。

4. **月度预算与超支警示**：
   - 支持设置当月总预算额度。
   - 自动按天计算「今日剩余可用额度」，超过 80% / 100% 自动变色预警。
   - 支持按重点分类（餐饮、购物等）单独设置限额。

5. **100% 本地安全 & 数据备份**：
   - 数据完全保留在浏览器 LocalStorage / 本地设备中，绝不上传任何服务器。
   - 支持一键导出 **JSON 全量备份文件**，支持一键还原。
   - 支持一键导出 **Excel / CSV 账单明细流水**，方便用电脑表格做二次分析。

## 🚀 方式一：即开即用（手机/电脑本地使用，强烈推荐）

1. 在终端运行启动脚本：
   ```bash
   cd /Users/dingwenhao/.gemini/antigravity/scratch/my-ledger-app
   npm start
   ```

2. 终端会打印出本地链接与**专属二维码**：
   - 电脑访问：`http://localhost:3000`
   - 手机访问：确保手机和电脑连同一个 Wi-Fi，用手机浏览器扫描二维码即可秒开。

3. **在手机上生成独立 App 图标（体验等同原生 APK，免去安装包烦恼）：**
   - **安卓 Chrome / Edge / 夸克 / 自带浏览器**：点击右上角或底部菜单中的 **「添加到主屏幕」** 或 **「安装应用」**。
   - **苹果 Safari**：点击底部分享按钮 ➔ **「添加到主屏幕」**。
   - 添加后，手机桌面上会生成一个单独的「清爽记账」图标，打开无网址栏、全屏运行、断网也能记账！

## 📦 方式二：编译打包为安卓 APK 安装包

项目已配置好移动端打包工程配置（Capacitor & GitHub Actions 自动构建）。

### 途径 A：使用 GitHub Actions 云端一键打包（推荐，无需本地配 Android SDK）
1. 将本项目推送到你的 GitHub 仓库（公开或私有均可）。
2. 在 GitHub 仓库页面点击 **Actions** 选项卡。
3. 选择 **Build Android APK** 工作流，点击 **Run workflow**。
4. 构建完成后，在 Artifacts 中即可一键下载编译好的 `.apk` 安装文件直接装到手机上！

### 途径 B：本地 Android Studio 编译
如果电脑上安装了 Android Studio 和 Android SDK：
```bash
npm install -D @capacitor/android
npx cap add android
npx cap open android
```
在打开的 Android Studio 中点击 **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)** 即可输出 APK 文件。
